### Intent Example
```bash
Create a new experiment named testfull under the project test-agent-mlops. Configure the experiment with standard-2-2, book a resource on the POS calendar from 12:00 to 13:00 today. Then launch the experiment and generate anomaly traffic. Once the file is available locally, create a BI VM named mlops-server for experiment testfull. Deploy the MLOps stack on it. Train a classification model with target column status. Publish the training results to MRS.
```
